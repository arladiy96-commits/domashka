# Домашка 📚

**Домашка** — отдельное семейное Android-приложение (Flutter) для помощи с заданиями второго класса в русскоязычной школе Казахстана. Приложение предназначено для родителей: решаем правильно, объясняем ребёнку, закрепляем похожими упражнениями.

## Уже реализовано в исходниках

- 📖 **Библиотека PDF** — импорт с телефона, хранение офлайн, просмотр настоящих страниц; автоматический текстовый указатель на каждую страницу. Можно поправить смещение печатных номеров относительно PDF.
- 🔎 **Страница + №** — поиск упражнения в тексте страницы, редактирование и подтверждение перед решением. Для страниц-сканов без текстового слоя Gemini распознаёт изображение страницы.
- 📸 **Карточки** — камера и галерея. Gemini читает фотографию, находит отдельные упражнения; текст нужно подтвердить.
- 🧮 **Математический движок** — независимые локальные вычисления простых примеров и уравнений, сверка с Grok, предупреждение при расхождении.
- 🤖 **Grok** — текстовые задачи, адаптация решения для тетради, объяснения и правила в формате 2 класса; генерация похожих заданий. При наличии ключа Gemini может отдельно проверить результат текстовых задач.
- 🎓 **Обучение** — тренировка по пяти темам, проверка ответов, повторение задач из истории.
- 🧾 **История** — сохраняет выполненные задания на телефоне.
- 🎨 **Премиальный интерфейс** — фирменная иконка, анимированная заставка, мягкие цвета и объёмные иллюстрации.

## GitHub Actions и APK

Workflow [.github/workflows/android-release.yml](.github/workflows/android-release.yml) на каждом push в `main` автоматически:
1. устанавливает Flutter stable + Java 17;
2. создаёт штатный Android bootstrap командой `flutter create`;
3. подготавливает сетевое разрешение, название приложения, иконки;
4. запускает `flutter test`;
5. собирает установочный Release APK;
6. публикует его в **GitHub Releases** с тегом `v0.1.<номер сборки>`.

Запуск вручную из GitHub: Actions → Build and publish Домашка APK → Run workflow.

## Сборка локально

Нужны Flutter stable (Dart 3.10+), Android SDK и Java 17. Из корня проекта:

    flutter create --org kz.domashka --project-name domashka --platforms android --no-pub .
    python3 scripts/configure_android.py
    flutter pub get
    dart run flutter_launcher_icons
    flutter run

## API-ключи и безопасность

Gemini и Grok подключаются **только в настройках на телефоне**. Ключи шифруются через Android Secure Storage, не сохраняются в GitHub или внутри APK. Книги и история остаются локально. Запросы отправляются поставщику модели только для соответствующей операции. Для работы не нужен собственный сервер.

- **Без API:** импорт и чтение PDF с текстовым слоем, простые примеры, уравнения, тренировки и история.
- **Gemini:** чтение фото, сканированных страниц PDF и опциональная проверка задач. Бесплатные лимиты зависят от аккаунта и модели.
- **Grok/xAI:** сложные задачи, объяснения и похожие задания. **API обычно платный** и тарифицируется отдельно. Приложение не делает платных вызовов без добавленного пользователем ключа.

## Ограничения первой версии

- На вход пока принимается PDF (EPUB, DOCX и другие форматы — будущие адаптеры).
- PDF со сложной версткой может требовать ручной корректировки текста упражнения; задача всегда подтверждается перед отправкой ИИ.
- Локальный решатель уверенно поддерживает отдельные арифметические примеры и простые уравнения. Для сложной словесной задачи подключается Grok. Если независимая проверка невозможна, приложение показывает это — не имитирует гарантию правильности.
- Для настоящих **автообновлений** позже понадобится постоянный release signing key. APK разных сборок с разными debug-подписями нельзя обновлять поверх друг друга. Не удаляйте приложение с важной историей до экспорта/резервирования данных; резервная копия будет отдельной функцией.
- Нельзя публиковать коммерчески защищённые учебники в открытом репозитории: PDF импортируются только лично на устройство.

## Gemini models
Для новых ключей используем `gemini-3.8-flash` вместо устаревшей 2.5 Flash. Старая сохранённая настройка автоматически мигрирует; можно получить список доступных Flash-моделей по своему API-ключу. При HTTP 404 приложение запрашивает доступный список и однократно повторяет операцию с совместимой Flash-моделью. API ключи остаются в Android Secure Storage.


## Grok / xAI
Поиск доступных моделей через `GET https://api.x.ai/v1/models` по личному API-ключу без inference-запроса. Если текущая модель не найдена (404), приложение может однократно повторить с поддерживаемой моделью сопоставимой ценовой категории. Повышение до более дорогой модели только по явному выбору пользователя. Понятные ошибки 401/403/402/429. **Groq Cloud (ключ `gsk_`) — другой провайдер**, его ключи не подходят к xAI.


## Groq Cloud
Теперь приложение использует API **Groq Cloud**, а не xAI Grok: `https://api.groq.com/openai/v1/chat/completions`. Поддерживается выбор моделей по ключу через `/openai/v1/models`, по умолчанию `llama-3.3-70b-versatile`. Существующий ключ `gsk_`, ранее введённый в поле Grok, переносится в защищённое хранилище Groq автоматически. Старая модель `grok-4.3` заменяется. Gemini и локальные вычисления продолжают работать. Бесплатные тарифы и ограничения задаются Groq Cloud.
