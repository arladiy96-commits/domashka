# «Домашка»: экспериментальная автономная камера

Для первого русского OCR использован локальный Tesseract4Android через
tesseract_ocr 0.5.0. Это контрольная реализация для измерения качества.

Почему пока не PaddleOCR: опубликованный flutter_paddle_ocr 0.0.2
предоставляет Android-модели PP-OCRv2/v3, но не готовый проверенный
PP-OCRv5 распознаватель русского. Новый flutter_paddle_ocr_v5 на ONNX
предполагает отдельную нативную сборку. После сравнения тестовых
снимков можно добавить его как второй локальный режим.

Модели rus и eng из tessdata_fast загружаются только во время сборки
APK командой python3 scripts/fetch_ocr_models.py; на телефон они
устанавливаются уже вместе с APK. OCR не обращается к сети.

В режиме «Офлайн» не бывает автоматического перехода к Gemini или Groq:
непонятные и неподдерживаемые задачи требуют исправления либо
показывают ошибку. Снимок в Gemini отправляется исключительно после
явного выбора пользователем вкладки «Gemini».

Пока OCR может ошибаться с цифрами, знаками, сложными таблицами и
диаграммами. Он не понимает геометрические рисунки — они остаются
видимыми на оригинальной фотографии. Каждый результат надо сверять
и при необходимости исправлять до вычисления.

Проверить: «Фото карточки» → «Офлайн» → нужное задание →
«Подтвердить и решить». При желании для того же фото переключить
вкладку «Gemini», чтобы сравнить качество.
