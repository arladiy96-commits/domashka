# Домашка — автономные математические правила (этап 1)

Существующая офлайн-база Оспанова не меняется. Добавлен независимый
слой строгого распознавания текстовых задач для случаев, которых нет
в подготовленном каталоге.

## Шаблоны
- remainder: первоначальное количество минус забрали — осталось.
- increase: первоначальное количество плюс добавили — стало.
- total: две явно указанные группы, вопрос о сумме.
- difference: сравнение количеств при совпадающих названиях предметов.
- change_twice: сначала вышли, затем вошли.
- two_groups_then_remove: сначала две группы, затем часть использована.

Сходные задания из учебника Оспанова, часть 1:
стр. 76 № 3 (две группы), стр. 89 № 8 (двухшаговая задача),
стр. 119 № 4 (разность количеств). Эта таблица лишь указывает
на связь с темами, а не утверждает совпадение дословных формулировок.

## Границы
- Проверяются количество чисел, формулировка вопроса и последовательность действий.
- Невозможные отрицательные остатки и неверно направленные сравнения
  отклоняются вместо выдуманного ответа.
- При распознанной задаче ответ рассчитывается локально, и AiService
  не вызывает Groq/Gemini даже при сохранённых ключах.
- Когда правило не распознано, существующий механизм Groq остаётся
  доступен при наличии ключа. Это НЕ всеобщий запрет сетевых запросов.
- Распознавание фотографий пока остаётся через Gemini. Локальное OCR
  является отдельным этапом и в этой ветке не реализовано.

## Проверка вручную
На главной открой «Решить вручную» и введи:
«В автобусе было 18 пассажиров. На остановке вышли 7,
а вошли 5. Сколько пассажиров стало?»

Ожидается 16, два действия, объяснение и тренировочные примеры.
Проверка тестами: flutter test test/math_engine_test.dart test/offline_ai_priority_test.dart
