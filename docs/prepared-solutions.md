# Подготовленные решения: локальный учебник Домашки

Схема дополняет существующий `domashka-offline-book` **версии 1** без
новых облачных сервисов и без изменения формата импорта.

## Установка

1. Подготовить персональный ZIP с `manifest.json`, `catalog.sqlite` и
   `pages/001.jpg` … `pages/NNN.jpg`.
2. В приложении выбрать «Библиотека» → «Офлайн-каталог ZIP» и указать ZIP,
   **не PDF**. Обычный PDF импортируется отдельно и не содержит решённых задач.
3. По странице и номеру найти задачу. Если решение проверено и подготовлено,
   появится «Открыть готовое решение (офлайн)».
4. Если исправить условие, готовый ответ автоматически отключается,
   и остаётся обычная ветка решения. Непроверенный текст никогда не
   используется как готовое решение.

## Структура SQLite

Сохраняются таблицы `exercises` и `exercise_structures` из текущего
импортёра. В `exercise_structures.structure_json` необязательно
допускается новое поле `ready_solution`:

```json
{
  "review_status": "first_pass_reviewed",
  "statement": "10 + 2",
  "blocks": [],
  "ready_solution": {
    "answer": "12",
    "notebook": "10 + 2 = 12",
    "explanation": "К десяти прибавили две единицы.",
    "rule": "Десять единиц — один десяток.",
    "math_verified": true,
    "practice": [
      {"question": "10 + 3 = ?", "answer": "13"}
    ],
    "diagram_blocks": [
      {"type": "base_ten", "tens": 1, "ones": 2, "label": "10 + 2 = 12"},
      {"type": "number_sequence", "values": [10, 11, 12], "label": "Считаем"},
      {"type": "table", "columns": ["Десятки", "Единицы"], "rows": [["1", "2"]]}
    ]
  }
}
```

`math_verified` должен быть `true` **только если проверены
вычисления**. Не смешивать успешное распознавание со смысловой проверкой:
число кружков/частей рисунка сверяется отдельно по оригиналу.
`review_status` обязательно `first_pass_reviewed`; иначе приложение
игнорирует `ready_solution`.

При чтении решения приложения больше **не зовёт Groq или Gemini**;
таблицы и схемы рисуются локально. Результат вместе с диаграммами
сохраняется в истории и доступен после закрытия приложения.

## Проверочный пакет

Пилот с **10 заданиями со страниц 4–6** создаётся локально из пользовательского
исходного PDF: страницы 4 (№ 1–3), 5 (№ 6–9), 6 (№ 1–3).
Другие страницы в пакете доступны как изображения, но пока **не считаются
разобранными**. Страница 66 в восстановленном исходнике содержит
плашку об отсутствующей странице, это не учебное задание.

**Не публиковать** полный PDF, страницы, ZIP или производный каталог
учебника в публичном репозитории. Пакеты предназначены только для
личного хранения и импорта на телефон.

## Проверки качества перед расширением

- Условия, значки математических операций и все числа сверены с оригиналом.
- Иллюстрации переданы точными количествами, а не приблизительным описанием.
- Таблицы не потеряли строки, столбцы, пустые клетки и подписи.
- Наборы ответов, правила и тренировочные задания проверены отдельно.
- Отсутствующие, спорные и творческие задания имеют явный статус и не
  маскируются под полностью проверенные.
